1) Locate/purchase a copy of GTA3 (ensure the `audio` folder contains the sound files—MP3/WAV—as well as `sfx.sdt` and `sfx.raw`).
The `Audio` folder is usually located inside the game image; you need to copy it to the game folder.

2) Find the appropriate game translation for your language (audio and textures) and copy it to the game folder (optional step).

3) Copy the files from the `re3psp_files` archive into the original game folder.

4) Launch Re3PSPTools, select the last tab (`build_repack`), choose the original game directory, and click "Start Repack." Wait just under 10 minutes for the repack compilation to finish; a folder named `[Your gta3 folder name]_psp` will be created.

5) Copy this folder to your PSP at `PSP/GAME/`.
